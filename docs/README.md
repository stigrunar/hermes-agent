# hermes-desktop-authoritative-main-live documentation

Read root `AGENTS.md` first, then `docs/AGENTS.md` for the scoped documentation contract.

## Documentation map

- `current/` — current product, architecture, API, operator, and design truth.
- `decisions/` — ADR/STORM rationale for durable decisions.
- `receipts/` — dated verification and acceptance receipts.
- `reports/` — bounded research, audit, and review reports.
- `archive/` — superseded material retained for provenance.

Root `ROADMAP.md`, `BACKLOG.md`, `TASKS.md`, and `CHANGELOG.md` remain the canonical direction, candidate, execution, and delivered-history surfaces.
